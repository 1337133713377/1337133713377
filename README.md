### [`REKA`](https://github.com/1337133713377/reka) — la console de mixage tout-en-un pour Windows

> Voicemeeter pour le son, tes plugins VST pour les effets, **une seule fenêtre** pour tout piloter.

```diff
+ Faders, mutes, VU-mètres et routing de Voicemeeter Potato / Banana dans une seule console
+ Plugins VST2, VST3 et CLAP par strip : ajout, réglage, réordonnancement à la souris
+ Routing en un clic vers Monitor, Mic Out, Discord et OBS
+ Volume par application, jauges de charge CPU / GPU, thèmes
+ Un seul .exe, rien à installer, mises à jour automatiques
```

| | |
| :-- | :-- |
| **Stack** | `Python` · `Qt 6 (PySide6)` · `Lua` · `PyInstaller` |
| **Intégrations** | Voicemeeter Remote API · REAPER · Windows Core Audio · WinRT |
| **Qualité** | Suite de tests `pytest` · build Windows automatisé avec GitHub Actions |
